# 1_termo
Material de Aula para o 1° TERMO - LOPAL - SOP - ARI - LER

🐍 LOPAL (Lógica de Programação em Python)

A disciplina desenvolve a capacidade de traduzir problemas reais em soluções computacionais estruturadas. O aprendizado utiliza a linguagem Python por sua sintaxe limpa e alta legibilidade. Os conceitos base envolvem a manipulação de variáveis para armazenar dados e a aplicação de estruturas condicionais e de repetição para controlar o fluxo da aplicação. O conteúdo também aborda a criação de funções, que isolam blocos de código para reaproveitamento e organização do software.

💻 SOP (Sistemas Operacionais)Conceito: 

Este conteúdo estuda a camada de software responsável por gerenciar o hardware e servir de plataforma para os aplicativos. O foco está no entendimento de como o sistema operacional administra a CPU através do escalonamento de processos. Também são analisados os mecanismos de alocação de memória RAM e a organização lógica do sistema de arquivos no disco rígido. A disciplina explica a coordenação de recursos para garantir a segurança e a estabilidade da máquina.


🌐 ARI (Arquitetura de Redes)

A matéria detalha o funcionamento, o design e a interconexão dos sistemas de comunicação de dados. O estudo abrange as topologias físicas e lógicas que determinam como os nós de uma rede se organizam. A base teórica fundamenta-se nos modelos de camadas OSI e TCP/IP, mapeando o caminho do dado desde a aplicação até o meio físico. Também são discutidos os principais protocolos de comunicação e o papel de dispositivos como roteadores e switches.

📋 LER (Levantamento de Requisitos)

Fase crucial da engenharia de software voltada a compreender e documentar o que deve ser construído. O processo envolve o uso de técnicas como entrevistas e observação para extrair as necessidades dos clientes e usuários. O analista classifica as descobertas em requisitos funcionais, que ditam os comportamentos do sistema, e requisitos não funcionais, que definem critérios de qualidade como segurança e desempenho. O resultado final é uma especificação técnica que guia a equipe de desenvolvimento.
